# Прокси GigaChat для Evgenia Eats

Приложение работает в браузере, а GigaChat API из браузера недоступен (нет CORS, сертификат Минцифры).
`index.js` это маленькая функция-посредник: получает фото от приложения, отправляет в GigaChat, возвращает ответ.
Ключ в функции не хранится, приложение присылает его с каждым запросом.

## 1. Ключ GigaChat

1. Зайти на https://developers.sber.ru/studio (вход по Сбер ID).
2. Создать проект "GigaChat API" для физлиц.
3. В проекте: "Настройки API" -> "Получить ключ". Скопировать **Authorization key** (длинная строка, показывается один раз).

## 2. Функция в Yandex Cloud

1. https://console.yandex.cloud -> Cloud Functions -> "Создать функцию" (имя любое, например `gigachat-proxy`).
2. Среда выполнения: Node.js (последняя версия из списка).
3. В редакторе создать файл `index.js` и вставить в него содержимое `index.js` из этой папки целиком.
4. Точка входа: `index.handler`.
5. Таймаут: **60 секунд** (по умолчанию 3, этого не хватит). Память: 128 МБ.
6. "Сохранить изменения".
7. На странице функции ("Обзор") включить переключатель "Публичная функция".
8. Скопировать "Ссылку для вызова" вида `https://functions.yandexcloud.net/...`.

## 3. Приложение

Настройки -> "Кто распознаёт фото" -> GigaChat. Вставить ключ из шага 1 и ссылку из шага 2, сохранить.
Вернуться на Claude можно тем же переключателем, ключ Anthropic остаётся на месте.
